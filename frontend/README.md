# Frontend

React-Oberfläche (Vite) der Customer Intelligence Platform: Arbeitsliste,
Kundenliste, Kundenakte und Dashboard gegen die Spring-Boot-API.

Start mit `npm install && npm run dev` auf `http://localhost:5173`. Die
API-Adresse kommt aus `.env` (`VITE_API_BASIS_URL`), Vorlage in `.env.example`.

Verbindliche Gestaltungsvorgaben stehen in `DESIGN.md`.
